# Learning Track（学习主线）

> 目标：在“学习阶段”先系统吸收成熟策略范式与因子工程方法，再逐步沉淀可执行的个人交易系统。

## 主线 1：策略范式学习（先看成熟，再做原创）

聚焦可复用的成熟框架，避免一开始陷入参数细节。

- 趋势跟随：多周期动量、均线结构、突破类（Donchian 等）
- 波动管理：ATR 止损、波动率分位过滤
- 量价确认：放量突破、缩量回调、量价背离
- 市场状态过滤：大盘/主流币风险偏好（risk-on / risk-off）

阶段产出：
- 每周沉淀 2~3 个“策略卡片”（定义、适用场景、常见失效）
- 形成 `strategy_cards/`（后续可扩展）

---

## 主线 2：因子库建设（先广泛收集，再稳定筛选）

先建立候选池，再做优胜劣汰。

每个因子统一记录：
- 因子定义（数学表达或规则）
- 直觉解释（为什么可能有效）
- 适用市场/周期（如 crypto `1m/3m/5m/15m`）
- 参数范围与默认值
- 失效场景（震荡/极端波动/流动性不足）
- 成本敏感度（滑点、手续费、资金费率、gas）

阶段产出：
- 先收集 20~30 个候选因子
- 第一轮筛到 6~10 个可用因子

---

## 主线 3：缠论专项（主观概念 → 规则化表达）

缠论学习重点是“可编程化”，而不是只看图形。

- 拆解对象：笔、线段、中枢、背驰
- 把判定标准写成可执行规则（阈值/窗口/确认机制）
- 与趋势/动量因子做并行比较，而不是直接替代
- 优先研究含回测与风控模块的开源实现

阶段产出：
- 缠论要素到规则的映射清单
- 最小可运行信号版本（不追求一开始最优）

---

## 当前学习阶段的执行节奏（约定）

1. 先做单因子验证，不急于多因子融合与机器学习。  
2. 评估三项核心指标：
   - 净收益
   - 最大回撤
   - 成本后收益（扣滑点/费用后）
3. 每完成一轮实验，更新 `docs/FACTOR_BACKLOG.md` 的状态与结论。  
4. 当可用因子达到稳定数量（如 6~10）后，再进入组合与策略优化阶段。
