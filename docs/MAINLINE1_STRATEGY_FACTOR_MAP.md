> 当前说明（2026-03-23）：本页是**学习与候选池地图**，不是 bot2/bot3 当前排班依据。当前短期排班以 `docs/BOT2_BOT3_POLICY.md` + `docs/BOT2_BOT3_STATE.md` 为准；本页主要服务于 `Scout` 与长期学习节奏。

> 适用范围：Crypto 短周期研究阶段（默认 `5m / 15m`，也接受 `1m / 3m` 用于更快验证高强度 alpha）。

## 0) 先建立统一研究框架（不然因子会越学越乱）

每个策略/因子都按同一模板记录：

- 假设：这个因子为什么可能赚钱？
- 信号：可计算定义（公式/阈值）
- 执行：如何下单（收盘价、下一根开盘、限价/市价）
- 成本：手续费、滑点、资金费率、gas（DEX）
- 风控：止损、仓位上限、熔断
- 评估：净收益、最大回撤、成本后收益（必看）

## 1) 趋势跟随模块（核心）

### 1.1 多周期动量（首要）

- 因子候选：
  - `mom_5m = close / close.shift(n1) - 1`
  - `mom_15m = close_15m / close_15m.shift(n2) - 1`
  - 多周期同向确认：`sign(mom_5m) == sign(mom_15m)`
- 你要学什么：
  - 窗口长度敏感性（n1、n2）
  - 趋势延续 vs 趋势衰减的边界
  - 不同市场状态下是否失效
- 复刻优先级：★★★★★

### 1.2 均线结构（趋势形态）

- 因子候选：
  - 均线斜率（MA slope）
  - 快慢线结构（如 EMA fast > EMA slow）
  - 价格到均线距离（偏离度）
- 你要学什么：
  - 趋势启动、趋势中继、趋势末端的差异
  - 均线类在震荡市中的误报问题
- 复刻优先级：★★★★☆

### 1.3 Donchian 突破（经典趋势系统）

- 因子候选：
  - `breakout_up = close > rolling_high(n)`
  - `breakout_dn = close < rolling_low(n)`
  - 结合 ATR 做止损/仓位控制
- 你要学什么：
  - 突破窗口 n 的稳定区间
  - 假突破过滤（可用量价或市场状态过滤）
- 复刻优先级：★★★★☆

> 当前已完成一个学习型模板：
> **1h EMA 结构给方向 + 5m Donchian breakout 给触发 + 连续收盘确认降噪 + ATR 止损控风险**。
> 当前结果说明：**裸 breakout 很容易被噪音打爆；先加确认，再加方向过滤，系统会明显更像样。**

## 2) 波动管理模块（风险与仓位）

### 2.1 ATR（学习重点）

- 因子候选：
  - `ATR(n)`
  - 止损：`stop = entry - k * ATR`（多头示例）
  - 仓位缩放：`position ~ target_risk / ATR`
- 你要学什么：
  - ATR 用作“过滤器”还是“止损器”
  - ATR 参数和交易频率、回撤的关系
- 复刻优先级：★★★★★

### 2.2 波动率分位过滤（Vol Regime Filter）

- 因子候选：
  - 实现波动率 `rv_n`
  - 分位过滤：仅在 `q_low < rv_n < q_high` 开仓
- 你要学什么：
  - 极端高波动阶段是否应降仓/停机
  - 低波动假信号阶段如何过滤
- 复刻优先级：★★★★☆

## 3) 量价确认模块（提高信号质量）

### 3.1 成交量异常（Volume Spike）

- 因子候选：
  - `vol_z = (vol - mean(vol,n)) / std(vol,n)`
  - `vol_z > z_th` 作为放量确认
- 你要学什么：
  - 放量突破与放量出货的区分
  - 阈值提高后，胜率与机会数量的权衡
- 复刻优先级：★★★★★

### 3.2 缩量回调（Trend Pullback）

- 因子候选：
  - 主趋势向上 + 回调时成交量低于均量
  - 回调结束再放量恢复作为二次确认
- 你要学什么：
  - 回调窗口、确认窗口如何定
  - 与均线/动量模块联动
- 复刻优先级：★★★★☆

### 3.3 量价背离（Divergence）

- 因子候选：
  - 价格创新高但量能或动量指标不创新高
  - 用滚动斜率/相关性做规则化判定
- 你要学什么：
  - 背离后的延迟确认（避免太早反向）
  - 趋势市与震荡市表现差异
- 复刻优先级：★★★★☆

## 4) 市场状态过滤模块（是否开仓）

### 4.1 Risk-on / Risk-off 门控

- 因子候选（先用简单可得数据）：
  - 大盘趋势（如 BTC/ETH 15m-1h 趋势同向）
  - 市场波动状态（极端波动期降仓）
  - 流动性状态（成交额阈值）
- 你要学什么：
  - “先判断环境，再启用策略”
  - 同样信号在不同 regime 下收益差异
  - 区分“弱有效过滤器”和“能跨阶段稳定抬升策略”的环境门控
- 复刻优先级：★★★★★

> 当前阶段结论（2026-03-09）：
> 已完成 trend/choppy first baseline gate 与 market-level risk-on/off v1 的初步验证。
> 结论不是“risk-on/off 无效”，而是：**已经理解它的角色定位，也看到它在长样本 / rolling 上有启发，但当前还不值得继续围绕自家 baseline 炼丹**。
> 因此下一步先回到 **概念梳理 + 文献扫描 + 因子候选池整理**，再进入下一轮高质量复刻。

## 7) 复刻路线（可直接执行）

### Phase A：地图回顾 + 概念收束（当前阶段）

- 回看 map，确认哪些已经学会，哪些只是“听过”
- 把因子 / 过滤器 / 环境门控 / 执行层的边界讲清楚
- 暂不继续围绕当前 baseline 微调

### Phase B：文献扫描 + 顶尖研究者常见因子整理

- 读经典研究
- 记录常见因子家族
- 理解每类因子的适用市场、适用周期与常见失效方式

### Phase C：候选因子池排序

- 给候选因子打标签：
  - 适合 5m/15m 吗
  - 为什么可能有效
  - 复刻成本高不高
  - 优先级高不高
- 只选 1~2 个高优先级因子进入复刻

### Phase D：高质量单因子复刻

- 每次只测一个因子
- 固定评估口径：净收益、最大回撤、成本后收益
- 结果写入：`docs/FACTOR_BACKLOG.md`

### Phase E：双因子组合与三模块融合

- 示例：`多周期动量 + 成交量异常`
- 示例：`Donchian + ATR`
- 关注是否减少回撤而非只追收益峰值

### 8.4 缠论专项当前起点（2026-03-10 更新）

当前缠论专项**只聚焦 `chanlun-pro`**，不同时发散到多个仓库。

当前不是把整套缠论理论一次学完，而是先回答：
**这里面哪些对象最像可编码、可验证、可进入当前 `momentum` 候选池的 alpha 候选。**

#### 第一阶段先学什么

1. **逐 Bar 增量计算思路**
   - 理解缠论对象不是静态一次性算完，而是随着新 K 线到来不断更新、确认，甚至消失。
   - 这是理解“信号确认 / 信号消失 / repaint 风险”的关键。

2. **对象链条与依赖关系**
   - `K线 -> 分型 -> 笔 -> 线段 -> 中枢 -> 买卖点 / 背驰`
   - 先把生成顺序看清，再讨论每层对象是否值得提炼为 alpha。

3. **多级别联立 / 区间套在系统中的角色**
   - 高级别结构更像：方向过滤 / 结构环境
   - 低级别买卖点更像：触发 / 确认增强
   - 区间套更像：多级别共振条件

4. **先提炼“最像 alpha”的对象，不追求完整理论覆盖**
   - 当前优先：`二买 / 二卖的程序化近似`、`回踩恢复`、`中枢突破后的回抽确认`、`多级别共振`
   - 当前不宜作为主攻：复杂背驰、完整中枢体系哲学化解释、平台/部署/UI 层内容

#### 第一阶段学习产出

- 把 `chanlun-pro` 里的核心对象翻译回当前研究框架：
  - 哪些属于方向过滤
  - 哪些属于触发
  - 哪些属于确认增强
  - 哪些更像环境/结构约束
- 从缠论专项里只选 **1 个最像 alpha 的对象** 进入 `docs/FACTOR_BACKLOG.md`
- 当前默认优先候选：**二买 / 二卖的程序化近似（作为 pullback recovery / 二次进场类 alpha 候选）**
