## 当前规则
- 范围：默认看已 `park` 的 queue-facing rank；当前优先 `Rank 50+`，再按 `50~79 -> 80~110 -> 1~24 -> 25~49` 轮转，避免总盯低号 rank
- 频率：每 `2h` 最多处理 `1` 条
- 默认输出：`keep_park` / `soft_reframe_candidate` / `derived_hypothesis_drafted`
- 默认不做：全量 hard/soft park 分类、批量重跑、改写主 TODO
- 若某条记录是 `derived_hypothesis_drafted`，则它应被写成 **bot2 可直接判断是否入板** 的短提案；当 fresh intake 不足时，bot2 可择优认领 **最多 1 条** 并写回 `TODO` 作为新的 Scout 候选。
- 可选标记：`hard_park_skip` = 默认不再复看，除非有新的外部证据
- 若原策略本质更像 `gate / filter / overlay`，bot6 默认优先把它改写成**更像 queue-facing alpha / setup / admission package** 的候选，而不是继续派生成更薄的 overlay。
