# Optimization Loop Logs

This directory stores autonomous 2-hour optimization / research loop records for `jerry/momentum`.

Naming convention:

- `YYYY-MM-DD_HHMM_<slug>.md`

Each log should capture:
- what was chosen,
- why it mattered,
- what changed,
- how it was validated,
- what the next step should be,
- and whether the run produced a safe commit.

The email body sent to Jerry should usually be this log file directly.
