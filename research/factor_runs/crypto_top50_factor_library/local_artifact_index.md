## 4. Why These Files Are Not in GitHub

The following patterns in `.gitignore` exclude these files:

```
data/
*.parquet
reports/artifacts/
```

**Reason:** These are large, reproducible artifacts. The source bars (~215K rows) can be re-downloaded via `scripts/fetch_crypto_top50_bars.py`. Factor values, metrics, and audit outputs can be regenerated by re-running the pipeline scripts. Storing them in git would bloat the repository unnecessarily.

**What IS in GitHub:** Scripts, documentation, registry, evaluation standards, skeleton, audit summary markdown, and warning summary markdown.

## 5. Quick Reference Commands

### List parquet files

```bash
find data -name "*.parquet" | head -50
```

### List metrics files

```bash
find reports -name "metrics.json" | head -50
```

### List research docs

```bash

```

### Read a parquet file in Python

```python
import pandas as pd

# Read bars
bars = pd.read_parquet("data/cache/crypto_top50_usdt_perp_1h/bars_1h.parquet")
print(bars.shape)  # (215042, 8)
print(bars.head())

# Read factor values
fv = pd.read_parquet("data/features/crypto_top50_usdt_perp_1h/mom_20h/factor_values.parquet")
print(fv.shape)
print(fv.head())

# Read labels
labels = pd.read_parquet("data/features/crypto_top50_usdt_perp_1h/labels.parquet")
print(labels.columns.tolist())  # ['timestamp', 'symbol', 'ret_fwd_1h', 'ret_fwd_4h', ...]

# Read metrics JSON
import json
with open("reports/artifacts/factor_eval/crypto_top50_usdt_perp_1h/mom_20h/metrics.json") as f:
    m = json.load(f)
print(m["label_metrics"]["ret_fwd_24h"]["IC_mean"])
```
