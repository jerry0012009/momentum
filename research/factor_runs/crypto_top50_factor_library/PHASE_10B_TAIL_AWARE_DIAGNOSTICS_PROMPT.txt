PM 指令：进入 Phase 10B — Tail-aware Signal Diagnostics。

中文名称：Phase 10B — 信号尾部分布与极端值诊断。

本阶段目标不是修收益、不优化策略、不翻转信号、不进入实盘。目标是解释并量化 Phase 10A / 10A-R 中出现的 RankIC 与 quantile spread 分歧：RankIC 多数为正，但 top-bottom spread 为负。当前 10A-R 初步结论是 non-monotonic tail behavior，尤其 bucket 0 极端正收益拉高 bottom leg。本阶段要把这个现象系统拆开，判断它是数据异常、尾部均值污染、真实均值回复结构，还是 horizon-specific signal direction 问题。

## 2. 本阶段要回答的问题

Phase 10B 必须回答以下问题：

### Q1. bucket 0 极端收益是否由少数异常样本驱动？

检查：

```text
signal × horizon × bucket
bucket 0 内部 return 分布
mean / median / winsorized mean
top contributors by symbol-date
最大单点贡献
前 1% 样本贡献
前 5% 样本贡献
```

### Q2. RankIC 正、spread 负是否主要来自 mean spread 对极端值敏感？

比较：

```text
mean spread
median spread
winsorized spread 1/99
winsorized spread 5/95
tail-trimmed spread
```

### Q3. signal 是否呈现非单调结构？

检查 5 桶和 10 桶：

```text
bucket_return_mean
bucket_return_median
bucket_hit_rate
bucket_count
monotonicity_score
bucket0_anomaly_score
```

### Q4. 方向是否 horizon-specific？

比较 original vs inverted signal：

```text
RankIC
standard spread
median spread
winsorized spread
tail-trimmed spread
bucket monotonicity
```

输出每个 signal × horizon 的 direction policy diagnostic。

### Q5. bucket 0 是否可能是数据质量问题？

检查 bucket 0 的 top contributors 是否集中在：

```text
特定 symbol
特定日期
低流动性 symbol
异常缺失 bars
极端 forward return
delisting / relisting 附近
价格跳变
```

如果不能确认，就输出 `NEEDS_DATA_AUDIT`，不要猜。
