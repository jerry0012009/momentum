# 别把 Fib 回踩确认继续写成“碰到 0.618 就算守住”：`0.618 hold / 0.5 fail` + volume surge，更像 15m retest_hold 的诚实定义

- 类型：GitHub
- 主题标签：fibonacci/retest-hold/confirmation/volume/failure-line/sma200/repo/crypto/15m
- 证据类型：工程经验 + 社区经验/待验证

## 1. 这次看了什么
看了 GitHub 仓库 `11Muhil/FibTrend-Pro-Strategy_Pinescript`（2025）。它表面上是在讲“Fib + volume + trend + ATR”，但对我们 desk 真正值得偷的，不是它宣称的高胜率，而是它把 **确认线** 和 **否决线** 分成了两条：上面用 `Fib 0.618` 做通过线，下面用 `Fib 0.5` 做失败线。

## 2. 核心结论
- 这个 repo 最有价值的旁支想法，不是“Fib 本身能赚钱”，而是 **把 retest_hold 写成带宽**：`close > fib618` 才算守住，`close < fib50` 就承认回踩失败。
- 它再叠一个很便宜的确认层：`volume > SMA24(volume)`。这比继续堆复杂结构词，更适合先做 15m 最小实验。
- `close > SMA200` 只是方向过滤，不该被误读成 alpha 本体；对我们更像 **只在大方向不逆风时测 Fib hold**。
- 作者 README 明说 **4H / 1D 更好，15m / 30m 更吵**。这反而是个优点：提醒我们别照抄 whole strategy，只偷其中最容易迁移到 15m 的确认/否决骨架。
- 一句话结论：**Fib 回踩确认别写成单点触发，先写成“0.618 通过、0.5 失守就撤”的成对定义。**
- 它是怎么证明这点的：**不是论文统计，而是可读 Pine 脚本 + 作者自报回测口径**；证据强度一般，但规则足够清楚，适合快复现。

## 3. 为什么和当前项目有关
这条最直接服务的是 `Fibonacci confirmation / retest_hold` 收口线。

原因很简单：我们现在缺的不是更多 Fib 词汇，而是一个 **更像交易规则的 through / fail 定义**。`0.618 hold / 0.5 fail` 正好把“守住”和“没守住”拆开，能直接减少“刚碰线就算有效回踩”的主观性。

顺带它也能给另外两条线提供辅助：
- 对 `breakout-short follow-up`：可镜像成跌破 0.618 后的 continuation / 回抽失败定义。
- 对 `EMA / PSAR raw alpha focus`：它不是替代 EMA/PSAR，而是可以当局部 **retest confirmation veto**。

## 4. 可复刻的最小实验
**研究假设**：在 15m crypto 里，`Fib 0.618 reclaim-hold + volume > SMA24 + HTF trend side`，比“只要回到 Fib 附近就开仓”更能提高 retest_hold 后续延续率。

**一个可计算定义**：
1. 在过去 `N=50` 根 15m K 上取 swing high / low，生成 `fib50` 与 `fib618`。
2. 多头候选：价格先回撤到 `fib618` 附近后重新收回其上。
3. 只在 `volume_t > SMA24(volume)` 且 `close > SMA200` 时记为确认通过。
4. 若入场后任一根 `close < fib50`，记为回踩失败；否则看未来 `k=6~12` 根是否走出 `+0.75 ATR / +1.0 ATR` 延续。

**最小回测切口**：
- 资产：BTCUSDT、ETHUSDT、SOLUSDT perpetual
- 周期：15m（执行），可加 1h 方向过滤做敏感性对照
- 样本：近 12 个月

**最先看 2 个指标**：
- `failure-before-target rate`：先掉回 `fib50` 的比例
- `target-hit within 12 bars`：确认后 12 根内打到 `+1 ATR` 的比例

**首轮对照组**：
- A：裸 `fib618 reclaim`
- B：`fib618 reclaim + volume>SMA24`
- C：`fib618 reclaim + volume>SMA24 + close>SMA200 + fib50 failure line`

如果 C 组只是减少交易数、却没明显改善 `target-hit / MAE / failure-before-target`，这条思路就别再升格。

## 5. 风险与保留意见
- 这个 repo 的回测主口径偏高周期，直接外推到 15m 很危险。
- 它用 rolling high/low 直接算 Fib，未必等于真正结构 swing，可能带来 level 漂移。
- `volume > SMA24` 在 24/7 crypto 里很粗糙，容易把亚洲冷时段和美盘活跃时段混在一起。
- 仓库只给多头模板；若要迁移到 breakout-short，必须单独验证短侧对称性，不能默认镜像成立。
