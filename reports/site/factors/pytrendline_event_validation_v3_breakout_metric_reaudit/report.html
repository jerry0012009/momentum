PyTrendline v3 breakout metric re-audit

Generated: 2026-03-13 19:19 UTC

这页只做一件事：复核上一版 breakout side audit 里最容易误读的指标，避免把“breakout 本来就该穿线”误当成“所有 breakout 都几何失真”。

结论先说：上一版最醒目的 100% close-based 指标，主要是在重复 breakout 定义本身，不足以证明“全部 breakout 行都坏了”。真正值得修的 blocker 是：严格几何异常仍然存在，但规模远小于 100%；另外 purged 样本里还保留了 1 条完全镜像、且 crossed_lines_share = 100.0% 的 paired breakout row。

Plain-language summary

  • 发现了什么：对 close-based breakout 来说，support line > event close / resistance line < event close 本来就很容易成立，因为这恰好是“收盘价穿过线”的定义。所以上一版把这个 100% 当成“通用 inversion”是过头了。
  • 真正更有信息量的检查：看线是不是已经跑到了整根事件 bar 的另一边，也就是 support 是否高于 event high、resistance 是否低于 event low。这才更像“这条线在事件发生前就已经几何失真”。
  • 当前 purged 样本的严格异常占比：support_breakout_raw 是 18.8%，resistance_breakout_raw 是 22.0%。也就是说，问题仍然真实存在，但并不是“100% 全坏”。
这轮没有声称的事：还没有重跑修复后的最小样本，所以这页不是 fix closure。它完成的是 把 fix 目标重新描述准确：下一步应该瞄准“严格几何异常 + exact mirrored pairs”，而不是假设所有 breakout 记录都该被判死刑。

What was found / not found / reliability

  • Found: 所有 breakout 类型的 legacy_close_based_share = 100%，但这主要反映的是 close-based breakout 定义，不是一个好的“坏样本占比”指标。
  • Found: 更严格的 strict_wrong_side_share（support 高于整根 bar 的高点 / resistance 低于整根 bar 的低点）在 purged 样本里大约落在 18%~24%，说明还有真实的 side / geometry 污染需要处理。
  • Found: exact mirrored pair 在 purged 样本里虽然只剩 1 条，但这条 paired row 是彻底坏的：crossed_lines_share = 100.0%、both_inverted_share = 100.0%、close_between_lines_share = 0.0%。
  • Not found: 没有证据支持“当前所有 breakout 行都几何失真”。
  • Not found: 也还没有证据支持“support breakout / resistance breakout 已经足够干净，可以被当成两条独立 alpha”。
  • Reliability: 对“旧指标被过度解读”的判断是 high；对“仍有一小块真实坏样本要修”的判断也是 high；对修完后 alpha 结论会怎么变，当前仍是 medium。
