  • 对当前最值得做的 OCO 家族（TP 1.25 / SL 1.00 / timeout 8）来说，maker-first 版本从无 BE≈10474.19% 提升到 BE@1ATR+cost≈11290.35%；但 taker 版本从≈11103.88% 小幅回落到≈11018.61%。这说明 break-even 的价值和 entry 口径是耦合的。
  • 对 TP 1.00 / SL 0.75 / timeout 16 这组，BE@1ATR+cost 和无 BE 几乎完全一样（≈5253.89% vs ≈5253.89%），因为 1ATR 触发点已经和 TP 太接近；而更早的 BE@1R+cost 反而把收益打到≈3852.26%，说明 stop 抬得太早会把 continuation 的肉提前切掉。
  • 这轮的 BE 不是抬到名义 entry，而是抬到 entry + cost buffer；平均 buffer 规模大约在 9.87 bps，已经把开平手续费、预估滑点和 funding buffer 算进去了。为避免路径偷看，BE 触发后从下一根 5m 才生效。

关键口径：break-even 触发后从下一根 5m 才生效；抬 stop 的目标不是名义 entry，而是 entry + cost buffer。cost buffer = 开仓成本 + 预估 stop 平仓成本 + timeout 对应 funding buffer。
