Trendline Confirmation Ladder Report

这是 PyIndicators track 的第 8 份回测报告。目标不是继续加大参数搜索，而是单独回答：多一层 confirmation，是否真的能提升质量，并且值得付出样本数收缩的代价？

scope 8 个 crypto（BTC / ETH / SOL / BNB / XRP / DOGE / ADA / AVAX）samples 60m / 365d + 60m / 730d

important 这页先做的是 operational confirmation ladder，即基于当前已实现的 close-persistence / inside-hold 口径做比较；还不是完整的 raw_breach → close_confirm → confirm1 → confirm3 → retest_hold 全事件宇宙。

示意图：为什么要做 confirmation ladder？

Q&A · 这份报告想得到什么结论？

Q1. 这份报告想回答什么？
它不想继续泛泛地问“这条策略整体行不行”，而是更具体地问：多一层 confirmation，是否能显著提升质量，并且值得付出样本收缩的代价。
Q2. 为什么要单独做第 8 份报告？
因为前面的 slope audit 已经告诉我们：该研究线不能再整体推进，只能在保留下来的 subset 上继续做“质量提纯”。confirmation ladder 正是提纯这一步。
Q3. 这份报告里最该看的是什么？
先看 breakout ladder 总表：更强确认有没有把 breakout 真正救起来；再看 retained rebound subsets：`flat` / `down_high` 在更强确认下是变好，还是只是样本塌缩。
Q4. 我们最想得到什么研究结论？
最理想的结论是：在 retained rebound subsets 内，存在一档确认强度，让 positive_asset_ratio 和 mean_total_return 都上升，而 trade retention 没有塌得太狠。这样它才值得继续推进成下一轮默认口径。
Q5. 如果结果不支持更强确认呢？
那也同样有价值：说明这条线的提升空间有限，或者 confirmation 带来的滞后抵消了质量改善。到那一步，我们就更有底气把这条线当 feature 或直接收束。

How to use this page

  1. 先看 breakout ladder：确认更强后，breakout 是否真的变得像样？
  2. 再看 rebound overall：确认更强是否只是“样本变少”，还是质量真提升？
  3. 最后只看 retained subsets：这一步才决定下一轮默认 confirmation 口径该放在哪一档。

如果 retained subsets 内存在一档确认强度，让收益质量改善而 trade retention 仍可接受，这条线就值得继续推进；否则更可能停留在 feature / park。
