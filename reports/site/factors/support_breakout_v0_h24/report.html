这页是 v3 final verdict 的后继原型页：前者回答“v3 最终留下了什么”，这页回答“把留下来的 support_breakout_raw @ h24 压成最小策略原型后，结果到底长什么样”。口径故意做得很朴素：事件触发后直接在 action_open 做空，固定持有 24 根 60m bar，不加成本模型，不做跨资产资金分配，只做同资产不重叠约束。

策略定义

  • 样本来源：复用 reports/artifacts/pytrendline_event_validation_v3/event_sample_purged.csv 中的 support_breakout_raw 事件。
  • 入场：事件对应的 action_timestamp / action_open 直接做空。
  • 出场：固定持有 h24，即 24 根 60m bar 后按收盘价平仓。
  • 去重：同一资产若上一笔仍在持有，则跳过后续事件，保证单资产不重叠。
  • 收益定义：以精确短仓收益 entry_open / exit_close - 1 计算，而不是简单取负号近似。

结论

  • 这批样本下，最简单的 breakout v0 并不差：48 笔、4 个资产全覆盖、平均单笔约 1.44%。
  • 它更像 h24 continuation short，而不是需要复杂过滤器才能勉强成立的东西。
  • 但这仍只是事件样本上的“策略化读法”，不是正式投资组合回测：没有做手续费、资金占用、跨资产并发资金分摊，也没有扩大样本窗。

收口定位：这条线现在该怎么用？

  • 保留：把 support_breakout_raw @ h24 先作为一个 条件性 alpha / v0 原型 保留。
  • 适合的市场条件：从这页的简单标签看，它在 flat 环境最顺手，在 down 环境也还能工作，但在 up 环境几乎没有边际。
  • 当前最值得优先验证的环境约束：若要加 first-pass gate，现阶段更像样的是 avoid_fluctuating，而不是把它机械地限死在 only_downtrend；因为前者在 OOS 里还能保留大部分样本，同时比 trade_all 更干净。
  • 最诚实的产品定位：它不是“全市场通吃”的成熟策略，而是一个更像 条件性 alpha / strategy-facing breakout-short 原型。
  • 研究线动作：这条 v0 不再继续发散找新花样，而是转入后续更正式的成本、rolling OOS、non-overlap / capital allocation、环境约束验证。

如果继续做 follow-up，允许做什么，不允许做什么？

  • 允许做的：更接近策略层的 honesty 检查——例如 cost / slippage sensitivity、rolling / OOS、non-overlap / capital allocation、以及更窄的环境约束验证（当前优先看 avoid_fluctuating）。
  • 也允许做的：把 support_breakout_confirm_1 作为紧邻确认变体，一起放进同样的成本 / 执行 / 环境约束框架里比较，但不要把它扩成第二条大而全独立研发主线。
  • 不允许再做的：把这条线重新扩回 v3 式的大全参数搜索、泛跨市场大工程、或重新开一轮“谁才是 breakout 家族第一名”的排序游戏。
  • 为什么要收这么窄：因为当前真正缺的不是再找新变体，而是回答这个 v0 原型在更真实的交易约束下还能不能站住。

如果下一步真做 split / regime honesty，应该怎么做才诚实？

  • 先固定当前 v0 定义：继续使用 support_breakout_raw @ h24、action_open 做空、固定持有 24 根 bar 的口径，不要因为某个 split / regime 表现差就临时改持有期或入场规则。
  • 至少同时看 gross 与 20bps：因为 first-pass 已证明 overall 并不是被轻微成本直接抹平，下一步更该关心的是 test 与 up regime 在现实一点的成本口径下是否仍持续偏弱。
  • split honesty 的核心问题：不是 train / validate 漂不漂亮，而是 test 是否还持续接近或低于零；如果主要收益只靠前段样本抬起来，这条线就更该停留在条件性原型，而不是升格成主策略。
  • regime honesty 的核心问题：不是强行要求每个 regime 都赚钱，而是要诚实回答：它是不是主要只在 flat 环境成立、在 up 环境就明显失效。若答案是是，就应该明确把它标成 conditional alpha，而不是假装它是通用 short。
  • 当前最像样的通过标准：这条线不需要每个 bucket 都赢，但至少不该只靠 train + flat 两块把 overall 结果抬起来；如果 test 在 20bps 下长期转负、且 up regime 没有任何可解释的约束办法，那就更像该停在 v0 原型页，而不是继续往 production short 包装。

一句话版：下一步不是再找新 breakout 变体，而是要先回答——这条 v0 在 test 与 up regime 的弱点，究竟是可接受的条件性 alpha 特征，还是已经足够说明它不配继续升格。
