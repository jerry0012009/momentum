1) 因子定义

UpWave(t)：t-3 为阳线，且 t-3..t 四天收盘都在 MA20 上方。

DownWave(t)：t-3..t 四天收盘都在 MA20 下方。

执行：t 日收盘确认信号，t+1 开盘进场，持有 N 天后收盘离场。

本报告主口径：long_only / short_only / long_short 三模式对比，且 不允许重叠持仓。

5.7 文字版研究结论（Q1~Q14）

  1. Q1 问题：UpWave 更适合作为入场信号还是交易许可过滤器？
    结论：UpWave 更像buy_hold模块，主要改善来自收益/回撤结构。
    实盘动作：若目标是降回撤，优先当交易许可；若目标是提收益，可保留入场角色但需叠加状态过滤。
  2. Q2 问题：该因子更擅长捕捉启动、延续，还是过滤失败抄底？
    结论：收益贡献主要集中在触发后 30 天窗口，且 MAE 在短期先扩张后收敛。
    实盘动作：若1–5天贡献主导可偏短持有；若10–30天贡献更高，应采用趋势持仓框架。
  3. Q3 问题：该因子最怕什么环境（震荡/波动收缩/过热）？
    结论：在低 ADX / 低 BBW / 低 ATR% 分位下，期望收益与胜率明显走弱，这些区间属于禁入候选。
    实盘动作：示例禁入：ADX<18 或 BBW分位<10% 时仅减仓/不追。
  4. Q4 问题：最佳持有期是否稳健，能否给默认区间？
    结论：持有期存在稳健区间，不建议追逐单点最优。
    实盘动作：默认选择稳健区间中值；极值点只用于研究不直接实盘。
  5. Q5 问题：MA 与连续天数 N 是否敏感，是否存在过拟合？
    结论：MA/N 在滚动 OOS 下存在差异，但并非单一参数统治，建议用稳健组合而非极值。
    实盘动作：参数敏感时采用软评分；参数稳健时可固化到执行规则。
  6. Q6 问题：成本/滑点条件下还能活吗？
    结论：各市场 break-even cost 差异较大，成本预算必须按市场单独约束。
    实盘动作：roundtrip fee 超过市场 break-even 时，降低换手并延长持有期。
  7. Q7 问题：与主信号如何组合最优（AND/分层/分位）？
    结论：组合方式上，分层仓位通常比纯硬过滤更平滑，且更利于维持机会覆盖。
    实盘动作：推荐先用 regime 分层仓位，再按资产类别决定是否叠加硬门槛。
  8. Q8 问题：能否作为风险管理模块独立使用？
    结论：分层仓位可压低组合级回撤并缩短修复时间，适合作为风控开关。
    实盘动作：DownRegime 触发时降杠杆/停高弹性策略；UpRegime 恢复常态仓位。
  9. Q9 问题：哪些资产更适配，白/黑名单如何定义？
    结论：资产适配存在明显分层：趋势占比高、成本可控、Calmar 更优的类别更适合白名单。
    实盘动作：按 rolling 正收益占比 + break-even + Calmar 制定白/黑名单并动态更新。
  10. Q10 问题：如何定义失效与降级，并执行停用规则？
    结论：当近6个月胜率持续低于历史且 MAE 恶化、sideways 占比抬升时，应判定失效风险上升。
    实盘动作：降级路径：入场信号 → 过滤器 → 停用，仅保留监控。
  11. Q11 问题：信号密度是否合理，资金利用率是否健康？
    结论：信号密度决定资金利用率与换手成本，密度过高需要配套分层仓位与多策略分流。
    实盘动作：按年度密度与空仓比设置容量阈值，避免单策略过度挤占。
  12. Q12 问题：2年训练+6个月验证的滚动 OOS 是否稳定？
    结论：2y+6m 滚动 OOS 下，MA30×N5 的中位 CAGR 最优（1.55%），但整体稳定性仍需持续监控。
    实盘动作：每月更新滚动窗口箱线图，按分位数（非均值）评估是否继续上线。
  13. Q13 问题：Tail risk 有多大，仓位和止损怎么定？

    实盘动作：按 worst-5% 与 MAE 动态约束仓位，并叠加 vol targeting。
  14. Q14 问题：综合来看，这个因子在实盘里的最优定位是什么？
    结论：综合看，该因子更适合做‘条件型趋势模块’（入场+过滤+风控联动），而非裸跑单模块。
    实盘动作：默认采用 long-first + regime gating + 成本预算 + 失效降级监控。

9) 风险与实盘约束

  • 高收益组合通常伴随高回撤，尤其加密市场。
  • A股做空存在现实限制（融券可得性、成本、限制）。
  • 成本、滑点、冲击成本会显著吞噬短持有期边际收益。
  • 容量受限：信号集中触发时，真实成交价格偏离会扩大。
  • 极端行情（跳空、熔断、流动性缺失）对该类规则不友好。

10) 最终定位建议

  • 相对更适用：趋势性强、波动较大的市场（如加密、部分成长股），并且持有期偏中长（10~30天）时表现更容易释放。
  • 相对不适用：长期震荡/均值回归市场、交易受限的做空场景（A股融券约束）以及高成本环境。
  • 定位建议：把 Up/Down Wave 作为“趋势过滤器 + 方向触发器”，与 ATR/ADX/仓位控制联用，而非单独裸奔策略。
推荐定位：作为趋势模块中的“信号过滤器/触发器”，与波动过滤、仓位管理、风险控制联动。
后续优化：OOS/滚动窗口验证、成本情景、多因子融合（ATR/ADX/量能/筹码）与参数稳健区间筛选。
