一句话结论

在同一份 BTC + ETH / 20d / 60m 最小样本上，修正后的 sampler 确实把我们关心的两类 breakout 脏样本清掉了：strict wrong-side rows 归零，exact mirrored pair groups 也归零；同时 breakout 样本没有被“一刀切删光”。

本轮到底测了什么

  • 同样本 A/B：同一份行情、同一组参数，只换 sampler 逻辑。
  • 样本：BTC-USD, ETH-USD，20d，60m。
  • 参数：window 72，snapshot step 24，confirm bars 2，tol mult 0.08，horizons 6, 24, 48, 72。
  • pre-fix = 只有 snapshot-side gate；fixed = 再加 event-time strict wrong-side gate + exact mirrored pair resolution。

这轮明确发现了什么

  • breakout_raw: strict wrong-side share 从 16.7% 降到 0.0%。
  • breakout_confirm_1: strict wrong-side share 从 38.9% 降到 0.0%。
  • breakout_confirm_2: strict wrong-side share 从 44.4% 降到 0.0%。
  • purged 样本里的 paired exact-match breakout groups：1 → 0。
  • raw breakout rows 仍然保留了可观样本，不是“修 bug = 全删样本”。

这轮没有发现 / 也不该过度声称什么

  • 这页不等于 full v3 45d/4-asset 主报告已经 closure。
  • 这页也不支持“support breakout 和 resistance breakout 已经可以当独立 alpha 信号”——侧别 alpha 解释仍要继续谨慎。
  • 这份 20d 双币最小样本没有强烈重现早先“大页里 side mean 完全相同”的现象，所以它更像 cleanliness audit，不是 full alpha verdict。
