Phase 2a · Momentum Ignition
二次点火追多
回答：事件已出现后，是否继续顺势追多、如何抓右尾？

策略逻辑：用量能突增 (volume ratio ≥ 3.0) 和小时涨幅 (1h return ≥ 1%) 识别事件后的二段 squeeze。信号小时之后，持仓从下一根 1h K 线开始。

演进过程：

  • V4 Trailing Stop：早期移动止盈版本，回测表现好但回测-实盘差异过大，已弃用 (DEPRECATED)
  • V4 SL-only：当前唯一执行版本。退出只允许固定 8% SL 或 96h timeout。Paper 与 live canary 共用事件检测和 V4 入场信号。
  • 同小时审计：测试 12:02 是否应允许直接用 11:00-12:00 完成K线交易，结论是不应放宽（新增 752 笔同小时交易均值 -6.06%、PF 0.18）。

Phase 2b · Short Reversal
冲高回落做空
回答：极端事件后买盘衰竭时，能否短线做空回吐？

策略逻辑：要求前 12h 放量冲高，随后从局部高点回落。是 Phase 2a 的相反交易假设——2a 追多，2b 抓反转。

回测结论：最佳组合 B_sv5.0_dr-2 / hold_8h_tp5pct 单笔净均值约 +0.83%，但收益集中在 B 类和 5% 止盈退出。参数族窄、止盈触发乐观风险高，2024 年明显变薄。

Phase 2c · Funding Squeeze Carry
负费率延续做多
回答：空头拥挤且价格继续上行时，能否吃 squeeze 与 funding carry？

策略逻辑：在 continuation 结构确认后，筛选极端负资金费率币种做多。不是 V4 信号，而是 funding 拥挤 + continuation 的独立方向。
