这条线到底在说什么

它真正值得偷的不是美股 continuation 筛选参数，而是一个更便宜的趋势健康度记分：

  1. 看最近一小段窗口里，有多少根 bar 真正体现了「回到 EMA9 附近但没破坏结构」；
  2. 把这种“最近尊重 EMA”的次数写成 ema_bounce_score / respect memory score；
  3. 先把这个 score 当成轻量 admission / sizing context，而不是直接升级成硬门；
  4. 把 ATR corridor、depth 这类更硬的距离限制保留为对照组，不默认并入主规则。

翻成人话：“最近确实常在 EMA 附近守住”有一点信息；但“必须贴得很近、刺破还不能太深”这类硬走廊，在 15m 上更像把信号和交易数一起筛坏。

两条轻量诚实守门

  • trade on：它只能作为现有 setup 的轻量 admission / sizing context。可挂到 breakout-short follow-up、Fib retest_hold、EMA/PSAR continuation，例如把 score14 >= 2 作为“允许正常准入，否则降级/半仓”的 shared 读数；但都不能单独开仓。
  • trade off：若没有既定 base setup，就不能单独开仓；若 score-only 的改善主要来自少做单、而不是更诚实地降低 false-follow / false-hold，就应直接 park。
  • lookahead / leakage：ema_respect_score 只能用 signal 当根及之前已完成 bar 的 EMA / low / close / open 关系构造；clean replication 强制 next-bar open + no-overlap，禁止同 bar 判定后按同 bar 成交；score window、touch band、以及是否要求 close>EMA / close>open 只能在训练段冻结，再去测试段验证。
  • hard corridor 只当对照组：dist<=0.75 ATR、depth>=-0.8 ATR 暂时只能做 control arm，不允许默认偷渡成主 admission 规则，因为当前快检已显示它更像过筛过度而不是 honest uplift。

为什么它现在配拿 1 次最小 clean replication 预算

对当前 desk 的价值它不是又加一条新 alpha，而是先给 EMA / Fib / breakout 这几条线补一个可复用的轻量趋势健康度读数。
已有快检证据当前快检已经给出对 desk 有用的硬结论：score-only 只是轻微减亏，但 hard corridor 会明显把质量和交易密度一起筛坏。这足以支持它进入 1 次最小 clean replication，而不是停留在泛泛 digest。
