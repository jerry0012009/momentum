两条轻量诚实守门

  • trade on：只把它降级成 shared level-memory gate。基础 setup 继续负责方向与价位；这层只回答候选 level 在最近 10 根左右是否已经出现过一次同价位 sweep。首轮冻结为：bull gate = low < priorLow && close >= priorLow && vol_ratio >= 1.2；bear gate = high > priorHigh && close <= priorHigh && vol_ratio >= 1.2；若与上一次 sweep 的 level 距离不超过约 0.5% * close 且间隔不超过 10 根 bar，则记作 same-level consecutive sweep，默认只让 consec2+ 参与 gate。
  • trade off：若只是单次 wick / 单次 close-back-inside，或 level 对齐并不成立，就不得硬说它形成了 level memory；这条线不能单独开仓，也不能偷渡成新的 breakout 主叙事。
  • lookahead / repaint / leakage：同价位判定、prior high/low、volume ratio 与 consecutive count 都必须只用 signal 当根及之前可得的 15m OHLCV 构造；desk 迁移统一冻结到 signal 当根及之前数据 + next-bar open + no-overlap，不得把之后几根是否 hold / fail 的结果反写回 count，也不得事后重选更好看的 level 容差。

为什么现在先 admit，不直接吹成 alpha

真实优点它直接回答 breakout-short / Fib retest / EMA-PSAR 共同缺的那个问题：这个 level 到底是第一次随机扫流动性，还是已经在最近几根里反复被市场 defend / reject。
关键保留quant digest 的代理快检已经提示：consec2+ 更像 admission / veto 的质量标签，而不是均值收益会自己抬起来的独立 alpha；样本也比 single-sweep 更薄。
当前最诚实结论两条轻量守门已过，因此值得进入 clean replication queue；但当前应被视为 level-memory gate，不是新的 shared breakout alpha。
