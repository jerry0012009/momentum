  • trade off：若只是碰到 drive edge、但没有穿过 edge + adaptive_offset，就不得把它说成 continuation confirm；它不能把 opening-drive 追价事后美化成趋势成立，也不能越俎代庖替代原始 trigger。
  • lookahead / repaint / leakage：drive_high/low、drive_mid、sessionVWAP、drive_range 与 adaptive_offset 都必须只用 signal 当根及之前可得的 15m/5m 数据构造；desk 迁移统一冻结到 signal 当根及之前数据 + next-bar open + no-overlap，不得把 breakout 后 4~8 bar 路径、future session path 或事后更漂亮的 session 切法倒灌回 gate。本轮若 crypto 24/7 的 session 边界仍未完全冻结，也必须如实写成“代理版 source intake”，不能偷渡成已可部署策略。
