这条线到底在说什么

核心不是“论文又证明动量有效”，而是更细一层：

  1. 同一套日内可预测关系里，可能同时存在 正号（continuation） 和 负号（reversal）；
  2. 这类关系在 no-jump、no-FOMC 这类更干净的 regime 里更稳定；
  3. 所以 desk 上已有的 breakout-short / Fib retest / EMA-PSAR continuation，不该默认都按“追原方向”放行。

翻成人话：不是所有 15m follow-up 都该追；有些时段更像延续，有些时段更像反手，先分方向再决定放不放行。

两条轻量诚实守门

  • trade on：它只能做现有 setup 的 direction-aware admission / veto gate。先有既定 base setup，再看当前 pocket 的 predictor_sign 是否与候选方向一致；若一致且不在 jump / FOMC blackout 内，才允许放行。
  • trade off：若 sign 关系主要靠事后挑时段，或 no-jump/no-FOMC 只是把样本砍到只剩少量幸存单，就必须停在 paper idea / evidence pool，不能升级成 shared gate。
  • lookahead / leakage：predictor_sign 只能由 signal 当根及之前、滚动过去窗口的已完成 bar 估计；no-FOMC 只能用事先公开的日程；clean replication 必须统一为 signal 当根及之前数据 + next-bar open + no-overlap。

当前硬结论

当前 verdictguard-passed / admit_to_clean_replication_queue
为什么不是直接 park和 Rank 117 不同，这条目前还没有被现成本地快检一眼判死。论文本身给出的信息足够明确：continuation 与 reversal 并存，而且在 no-jump / no-FOMC 子样本里更强，说明它至少值得拿 1 次最小 clean replication 预算。
为什么也不是直接升格因为它仍是论文口径，尚未证明在我们 desk 的 BTC/ETH/SOL 15m + next-bar open + no-overlap 条件下，改善不是单纯靠大幅砍单。当前最多只能先当 queue-facing candidate。

最小 clean replication 应该怎么做

  1. 固定 1 条 base archetype（优先 breakout-short follow-up 或 fib_retest_long）。
  2. 只用 BTC/ETH/SOL 120d 15m 本地 cache。
  3. 训练段先冻结：每个 intraday pocket 的 predictor_sign，以及 jump blackout / FOMC blackout 窗口。
  4. 测试段统一比较三臂：baseline / sign_gate_only / sign_gate_plus_blackout。
  5. 重点看：post-cost expectancy、false-follow / false-hold、trade retention，而不是只看胜率或只看某个小时 pocket 的漂亮切片。

它对 desk 的真实意义

  • 给 breakout-short：避免把所有破位 follow-up 都写成“继续追”。
  • 给 Fib retest_hold：回踩到位不等于默认顺势继续，先看当前 pocket 更像 continuation 还是 reversal。
  • 给 EMA / PSAR raw alpha：把 raw trigger 留在扫描层，把真正 admission 收紧成 direction-aware + regime-aware，而不是再往 trigger 本体里堆更多指标。
