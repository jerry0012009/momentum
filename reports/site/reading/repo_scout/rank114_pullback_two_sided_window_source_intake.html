这条线到底在说什么

它真正值得偷的不是 XAUUSD 的参数，而是一个更诚实的 post-trigger execution skeleton：

  1. SCANNING / ARMED：raw trigger 只负责把 setup 标成「值得观察」，不立刻进场；
  2. PULLBACK CONFIRMED：等 trigger 后出现 1~3 根逆向回撤，或一个有限深度的回踩；
  3. WINDOW OPEN：用最后一根 pullback bar 的 high/low 定义双边窗口；
  4. SUCCESS / FAILURE / TIMEOUT：顺向破边才允许 entry；反向破边就是 failure；超时没走出来就是 timeout。

翻成人话：别把 raw trigger 当入场，把它当 scan；真正的 entry 要等一个短窗口 verdict。

两条轻量诚实守门

  • trade on：它只能作为现有 base setup 的 entry-verdict overlay。可服务 breakout-short、fib retest、EMA/PSAR raw trigger，但都只能先当「scan → pullback → window verdict」，不能自己单独开一条新策略。
  • trade off：没有 base trigger 时不能单独开仓；如果改善只是来自大砍样本、事后挑最好窗口、或只在单一 symbol 偶然好看，就应直接 park。
  • lookahead / leakage：pullback、window、success/failure/timeout 必须全部只用 signal 当根及之前可见的数据来定义；clean replication 强制 next-bar open + no-overlap，禁止同 bar 判定后按同 bar 成交；offset、window bars、pullback depth 只能在训练段冻结，再去测试段验证。
  • timeout 必须写死：超时不是事后补丁，而是 setup 的一级状态。若迟迟不给 success，本身就是负信息。
