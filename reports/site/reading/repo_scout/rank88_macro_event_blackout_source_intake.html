两条轻量诚实守门

  • trade on：保留现有三条 archetype 的方向、entry 与 exit；overlay 只回答事件窗内是否该 blackout 或 size-down。首轮冻结成 FOMC/CPI 官方发布时间周围的固定风险窗：blackout[-1h,+1h]、size_down_0.5x、以及 hybrid[-30m,+30m] blackout + [+30m,+120m] size_down。
  • trade off：若不在事件窗内，overlay 不得强行改变原始信号；若只是事后觉得“这根像新闻 bar”，也不能回填成 veto。它不是独立 alpha，只是 shared risk overlay / sizing layer。
  • lookahead / repaint / leakage：事件时间只能来自事前公开的官方发布时间；desk 迁移必须统一成 signal 当根及之前数据 + next-bar open + no-overlap，不得用公告后 realized move、未来 volatility 或人工补标 risk window 倒灌回 gate。

为什么现在先 admit，不直接吹成 alpha

真实优点它直接针对 15m continuation / retest 最容易被宏观事件打穿的风险窗口，而且实现成本极低：公开日程 + 时间窗映射即可落地。
关键保留当前证据说明的是“事件窗波动显著抬升”，不是已经证明 blackout / size-down 一定提高净收益；它仍需最小 clean replication 才能决定 keep / promote / park。
当前最诚实结论两条轻量守门已过，因此值得拿 1 次最小 clean replication 预算；但若 improvement 主要靠把交易数砍空，或只是在事件窗极少的 pocket 上看起来更好，就应快速压回 park。
