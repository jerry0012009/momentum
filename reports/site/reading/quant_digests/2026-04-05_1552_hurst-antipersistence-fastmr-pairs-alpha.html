1. 先回答一句：base alpha 是什么？

base alpha = cross-asset pairs mean reversion。

更具体一点：

> 当两条本来经常一起走的币价关系突然拉开时，如果这条 spread 当下呈现 反持久（H < 0.5），那这次偏离更像“会回来的错位”，而不是“会继续跑开的新趋势”。

所以这里的 H < 0.5 不是单独拿出来装成一个高大上的 filter； 它服务的是一条能独立落地的 完整 pairs raw alpha：

  • 先找共动较强的 pair；
  • 再等 spread 偏到 1~2 个波动单位；
  • 只有当局部 H < 0.5 时才开仓做回归。

这就已经是可以写成 entry / exit / sizing / risk / cost 的完整策略，不只是解释型指标。

2. 为什么这轮值得写它？

结合当前研究池，最近 pairs / stat-arb 材料已经不少，但大多集中在：

  • pair admission（怎么筛对）
  • spread forecast（怎么预测）
  • threshold tuning（阈值怎么调）
  • HMM / DNN / ensemble（怎么把模型堆复杂）

相对少的，是这种更“朴素但好落地”的问题：

> 同一条 pairs shell，怎样只做“更快回归”的那一批偏离？

这篇 paper 值得补进素材池，主要因为：

  1. 它仍然是 raw alpha，不是纯 filter 题。

    2. 论文最后给的是可执行 pairs strategy，而不是只证明 Hurst 有统计学意义。

  2. 它对 short-cycle desk 很实用。

    3. 我们做 5m / 15m，最怕的不是“方向完全错”，而是仓位卡太久、手续费和资金占用把 edge 磨没。这个 paper 正面回答的是“怎么挑更快回归的 trade”。

  3. 它和现有 backlog 不重复。

    4. 现有很多材料在研究 pair 怎么选、spread 怎么估，但这篇的核心补充是： 在已经决定做 pairs mean reversion 之后，用局部记忆结构去挑 entry time。

  4. 它是开放获取全文，复现阻力低。

    5. 不需要靠摘要脑补，也不是只有结论没有规则。

4. 这篇 paper 到底做了什么？

4.1 数据口径很直白：Binance 公共价格、20 个大币、小时级、2019-2024

论文数据集：

  • 标的：按 2024-06-06 CoinMarketCap 市值前 20 的 crypto
  • 来源：Binance API
  • 频率：1h
  • 区间：2019-01-01 ~ 2024-06-05

也就是说，这不是靠私有订单流、私有清算数据或内部成交拿到的 edge， 而是能用公开 K 线重建的东西。

4.2 他们的 spread 不是简单 A-B，而是按 30 天波动做了风险配比

论文把 pair spread 定义为：

``text s_t = log(p_A,t) - b * log(p_B,t) ``

其中

``text b = std(lr_A, 过去30天) / std(lr_B, 过去30天) ``

翻成人话：

  • 不是 1:1 硬配；
  • 而是按过去 30 天波动把两边仓位粗略配平；
  • 这样做的目的是让 long/short 两腿的风险更接近，减少“一边天生更能跳”的噪声。

这点对 desk 很重要，因为它天然更接近可执行仓位，而不是只在研究纸面上看 spread。

4.3 Hurst 在这里是什么意思？

Hurst 指数 H 是个“看这段序列更像继续延续，还是更像来回拉扯”的指标：

  • H = 0.5：更像随机噪声，没明显记忆
  • H > 0.5：更偏持续，容易顺着原方向继续走
  • H < 0.5：更偏反持久，也就是更容易朝均值回去

论文用的是 Generalized Hurst Exponent (GHE)，q=1，并且只用过去数据滚动计算 local H，避免偷看未来。

他们测试的 local H 窗口有：

  • 1, 3, 5, 7, 10, 14, 21, 28 天
  • 都是在当前时点 前一小时截止 的滚动窗上算

4.4 关键发现不是“有点统计相关”，而是：H<0.5 时回归明显更快

论文先做了一个自然实验：

  • treatment：H < 0.5
  • control：H >= 0.5
  • 比较的是 spread 回到滚动均值所需的时间 HMR（hours to mean reversion）

他们控制了：

  • 同一对 pair
  • 时间要在前后 3~30 天内匹配
  • 波动水平一致（低 / 中 / 高）
  • 有些实验里还额外控制了 co-movement 桶

结果很干净：

  • 所有时间窗下，H < 0.5 都显著加快回归，p-value 都很小（多数几乎是 0）
  • 例如 TW = 5天 时，treatment 相比 control 的 median HMR 优势约 18 小时
  • 论文认为在 3~10 天 的 H 窗口里，信号强度和机会数量比较平衡
  • 若只看差异最大点，拐点大致在 10 天窗
  • 若兼顾可交易机会，作者后面主要聚焦 7 天窗

这很 desk-friendly：

> 它不是说 “H<0.5 所有时候都赚钱”，而是说 同样是 spread 偏离，H<0.5 的那批平均回得更快。

对于短周期 pairs，这比抽象地证明“均值回归存在”更有用。

4.5 更重要的是：这个效应不是只在某一种 pair-selection 方法下才成立

论文拿四种 co-movement / 相关性方法做了分层：

  • Correlation
  • Cointegration
  • Mutual Information (MI)
  • Dynamic Time Warping (DTW)

结论是：

  • 在四类 co-movement 刻画下，H < 0.5 的 faster-MR 效应都还在
  • 对 MI，高共动 pair 上效果略更强
  • 对 cointegration，中间档效果稍弱，但高 / 低两端都还显著

这句话对我们很有价值：

> H < 0.5 更像是 entry-time gate，而不是某一种特定 pair-ranking 方法的附属副产物。

也就是说，它可以直接插到我们已有的：

  • cointegration pair shell
  • correlation / distance shell
  • DTW / nonlinear similarity shell

里头去测，而不用推翻整个 pairs 框架重来。

5. 论文给出的完整策略壳是什么？

这点很关键，因为它决定这篇东西能不能算 raw alpha。

论文的交易规则并不含糊：

5.1 Entry

只有在 H < 0.5 时才允许开仓； 并且 spread 需要已经偏离均值 1~2 个波动单位。

具体地：

  • 若 s 位于 m + 1*std(m-s) 与 m + 2*std(m-s) 之间：
  • sell the pair
  • 即卖出 A、买入 B
  • 若 s 位于 m - 2*std(m-s) 与 m - 1*std(m-s) 之间：
  • buy the pair
  • 即买入 A、卖出 B

翻成人话：

  • spread 只要轻微偏一点不做；
  • 已经严重失控超过 2σ 也不在原始 entry 区间内追着做；
  • 只做 “已经偏了，但还没完全炸穿”的那一段回归窗口。

5.2 Exit

满足任一条件就平：

  1. spread 回到均值
  2. spread 继续偏离并超过 2σ
  3. 持仓超过 72 小时（3 天）

这已经是完整的：

  • entry
  • stop / invalidation
  • time stop

所以它不是“只有一个指标”。

5.3 论文回测里最该记住的几组数字

A. H<0.5 的 trade，真正回到均值时通常更快

论文比较了：

  • 满足 H<0.5 才开的实际 trade
  • 以及其它条件都满足、唯独 H>=0.5 的潜在 trade

结果：

  • 实际回归成功的 H<0.5 trade，中位持有期约 13h
  • 不满足 H<0.5 的那批，中位持有期约 22h

也就是大概快了 9 小时。

对于 short-cycle desk，这 9 小时不只是体验差异，而是：

  • 资金周转速度
  • fee / funding / borrow 消耗
  • 同时开仓数占用
  • overnight / regime drift 暴露

B. 组合容量会明显改善

论文用 MSOT（maximum simultaneous open trades，最大同时开仓数）看容量。

他们发现：

  • 加上 H<0.5 这个 gate 后，同时挂着的 trade 会少很多
  • 对纯 H 策略，ΔMSOT ≈ 0.3 × PortfolioSize

作者举的直观例子：

  • 当最多允许 20 个并行仓位时：
  • 不用 H gate，最大组合规模约 32
  • 用 H gate，可扩到约 66
  • 当最多允许 40 个并行仓位时：
  • 不用 H gate，最大组合规模约 65
  • 用 H gate，可扩到约 132

这不是说收益自动翻倍， 而是说它更像一个 “让 pairs 组合不那么堵仓” 的 entry redesign。

C. 论文自己的回测里，cointegration 选对法最好

Table A5 里，作者给出的收益汇总里：

  • Cointegration strategy：Profit % = 61.56%
  • MI：42.57%
  • H-ranked：38.67%
  • Correlation：38.63%
  • DTW：23.43%

这里要很小心：

  • 这是论文的历史回测汇总，不是 live PnL；
  • 里面的“investment”是作者定义的归一化资金口径，不要直接拿来当 desk 规模收益率；
  • 真正可用的信息不是绝对收益数字，而是：

    • 在这套壳里，cointegration 排 pair + H<0.5 entry，表现最好。

6. 对我们的 short-cycle desk，应该怎么读这篇？

6.1 它更像 5m / 15m 原型，不是天然属于 1m

这篇 paper 原始频率是 1h，所以最自然的移植顺序是：

  1. 先做 15m
  2. 再下探 5m
  3. 若 5m 能活，再考虑 3m / 1m

原因很简单：

  • 它研究的是 pair spread 的局部记忆结构，不是 book 级极短冲击；
  • 当你压到 1m 时，microstructure 噪声、交易所异步、wick、资金费率边界影响都变大；
  • 这条 alpha 的本体并不要求越快越好，它更要求 回归发生得够快且足以覆盖成本。

所以更诚实的 desk 读法是：

> 先把它当 15m -> 5m 的 pairs raw alpha 壳；若成立，再研究 3m / 1m 能否只作为 finer timing，而不是直接全频重做。

6.2 desk 版完整策略壳

Universe

第一版只做高流动大币 perp / spot，可选：

  • BTCUSDT
  • ETHUSDT
  • BNBUSDT
  • SOLUSDT
  • XRPUSDT
  • DOGEUSDT
  • ADAUSDT
  • LINKUSDT
  • LTCUSDT
  • AVAXUSDT

原因：

  • short leg 需要足够稳的流动性
  • pair spread 不能被冷门币一脚踢穿
  • 我们现在更需要稳健可复现，而不是 universe 扩张幻觉

Pair formation

每周或每两周滚动一次：

  • formation window：30d ~ 60d
  • 先跑 cointegration / correlation / MI 三种 ranking
  • 每种方法保留 top 10~20 pairs
  • 第一轮优先 cointegration，因为 paper 里这条最好

Spread

先完全照 paper 的风险配比：

``text s_t = log(p_A,t) - b_t * log(p_B,t) ``

其中

``text b_t = rolling_std(ret_A, 30d) / rolling_std(ret_B, 30d) ``

Signal

在 15m 上的第一版建议：

  • spread rolling mean / std 窗口：3d / 5d / 7d / 10d
  • local H window：优先测 3d / 5d / 7d / 10d
  • 开仓条件：
  • 1.0 <= |z_spread| < 2.0
  • H < 0.5
  • pair 仍在 admissible universe
  • 方向：
  • z_spread > 0：short spread
  • z_spread < 0：long spread

Exit

  • TP：z_spread 回到 0 附近（或 |z| < 0.15）
  • SL：|z_spread| >= 2.25 ~ 2.5
  • Time stop：
  • 15m 版本先试 24h / 36h / 48h
  • 5m 版本先试 12h / 24h / 36h
  • Optional veto：
  • 若 H 回升到 > 0.55 且 spread 继续恶化，可提前砍

Sizing

  • 每对 pair 按目标波动配仓
  • 单对 pair 风险预算先控在组合 NAV 的 25~50 bps
  • 同一资产的净暴露做聚合上限
  • 不允许过多高度重叠 pair 同时开仓（例如同一时刻 BTC-ETH、ETH-BNB、BTC-BNB 全开）

Cost

第一轮回测必须显式打进去：

  • taker / maker fee
  • bid-ask half spread
  • perp funding（若用 perp 对 perp）
  • 借币 / 现货 short 成本（若用现货 long-short）
  • 信号重叠导致的换手抬升

这条 alpha 的核心价值不是“单笔赚很多”，而是：

> 更快回归，减少卡仓，把毛 alpha 留到净 alpha。

7. 最小实验怎么做？

这轮最重要的不是写出花哨模型，而是尽快验证下面 3 个问题。

实验 1：先只验证 paper 的核心命题能不能在 15m 迁移

目的： 不先看 PnL，先看 H<0.5 是否仍然意味着更快回归。

  • universe：10 个最液的大币 perp
  • formation：过去 45 天做 cointegration ranking
  • 保留 top 10 pairs
  • 在 15m 上滚动计算：
  • spread
  • rolling mean/std
  • local H（3d / 5d / 7d / 10d）
  • 统计：
  • 所有 1<=|z|<2 的偏离事件
  • 分成 H<0.5 vs H>=0.5
  • 比较 time-to-mean-revert 分布

验收标准：

  • 如果 H<0.5 组的中位回归时间没有明显更快，或者优势小到 cover 不住成本，那这篇东西就别继续重投资源。

实验 2：再看它是不是能改善 pairs shell 的净值质量

目的： 验证它到底是提升胜率、缩短持仓，还是只是减少交易次数。

对比三组：

  1. baseline：1<=|z|<2 就做
  2. H-gated：1<=|z|<2 且 H<0.5
  3. stricter H-gated：1<=|z|<2 且 H<0.45

看这几项：

  • net PnL / trade
  • holding time
  • win rate
  • max concurrent positions
  • turnover
  • net Sharpe / Calmar

最关键的是： 如果 H-gate 只是把交易数量砍掉，但没有提升 PnL/trade、没有降低堵仓，那它在 desk 上的价值就会打折。

实验 3：把 15m pair signal 下钻到 5m 做 finer timing

目的： 检查这条 alpha 能不能继续往 short-cycle 靠，而不是只停留在中频。

做法：

  • 15m 负责 pair admission 与大方向 spread 偏离
  • 5m 再确认：
  • spread z-score 仍在同方向
  • local H 仍 < 0.5
  • 最近 3~6 根 bar 没有继续加速失控
  • 若 15m 触发但 5m 显示继续趋势化（例如 H 回到 >0.55），则延后或放弃入场

这一步的目标不是把策略复杂化， 而是回答一个非常实际的问题：

> Hurst 这条线是只适合 pair-level admission，还是也能用来细化执行时点？

8. 我现在对它的判断

我的结论是：值得进研究池，而且优先级不低。

但理由不是“它证明了 Hurst 很神”，而是：

  1. base alpha 很清楚：就是 pairs mean reversion
  2. 完整策略壳很清楚：spread 偏离 + H<0.5 + mean exit + 2σ/time stop
  3. 最贴近 desk 的价值很清楚：挑更快回来的 trade，减少卡仓与成本侵蚀
  4. 迁移到 15m / 5m 很自然：不需要依赖稀有数据
  5. 它能服务现有 pairs 素材池：不是替代，而是给现有 pair shell 一个更有物理含义的 entry redesign

如果这条线最后跑不出来，我最怀疑的地方也很明确：

  • 小时级论文迁到 5m 后，microstructure 噪声把 H 估计搞脏
  • crypto 近两年的结构和 2019-2024 不一样，stable / majors 的相关性状态变了
  • 成本、funding、滑点和组合拥挤把纸面 faster-MR 吃掉

但这些都属于很适合最小实验快速证伪的问题。

所以它符合 bot7 当前这轮最该做的事：

> 不是继续围着某个固定形态内循环，而是给 desk 补一条新的、可执行的 raw alpha 组件。

9. 这轮建议直接开工的参数表

为了省研发时间，第一轮我会直接这么测：

  • 频率：15m
  • universe：BTC/ETH/BNB/SOL/XRP/DOGE/ADA/LINK/LTC/AVAX
  • pair ranking：cointegration top 10
  • formation：45d
  • spread hedge ratio：30d rolling vol ratio
  • local H：GHE q=1
  • H window：3d / 5d / 7d / 10d
  • entry：1.0 <= |z| < 2.0 且 H < 0.5
  • stop：|z| >= 2.25
  • take profit：|z| < 0.15
  • time stop：36h
  • rebalance：每周
  • 成本：双边 taker fee + 0.5 tick spread slippage + funding

然后只回答 3 个问题：

  1. H<0.5 是否真的缩短回归时间？
  2. 净收益 / 单笔收益是否改善？
  3. 最大同时开仓数是否下降？

如果三项里能稳住两项，这条线就值得继续往 5m 和更细 execution 打磨。
