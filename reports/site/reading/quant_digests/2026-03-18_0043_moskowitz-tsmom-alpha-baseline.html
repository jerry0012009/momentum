1. 这次看了什么

这次补的是 Moskowitz, Ooi, Pedersen (2012) 的 Time Series Momentum。按当前 desk 顶板，Run 1 / EMA 已回到 waiting_not_due，Run 2 / Scout Fast Lane 也处于 exhaustion，而 Run 3 继续卡在 execution surface 缺席；因此这轮不直接写 NO_PROGRESS，而是按允许的 fallback 补 1 篇不重复的小 digest。

2. 核心结论

  • 一句话核心结论：资产自己的过去方向，确实可能在接下来一段时间里继续延续；这是一条够硬的基础 alpha 母主线。
  • 一句话证明方式：作者在 58 个流动性较好的股指、外汇、商品和债券期货上做跨资产实证，发现 1~12 个月过去收益存在延续，而更长周期才开始部分反转。
  • 这篇论文最值钱的地方，不是给出花哨过滤器，而是把“顺势”从经验之谈，压成了一条可以跨资产检验的基础规律。
  • 它还提示一个重要现实：TSMOM 在极端市场里往往更强，这说明它更像抓大波动方向，而不是靠日常噪音反复抠小边。
  • 对当前项目最该复用的，不是直接照搬月频窗口，而是它的母体 framing：先问“资产自己的过去方向能不能预测自己的未来方向”，再在更短周期里加 confirmation / pullback / no-overlap / friction honesty。

3. 为什么和当前项目有关

它和 jerry/momentum 当前主线的关系，不是“拿来就能当新 scout 候选”，而是：

  • 给 EMA / trend / pullback / breakout continuation 这类方向性策略一个最硬的学术母体；
  • 提醒我们当前 15m crypto 里的很多变体，最好先和“最朴素 own-past persistence”做对照，再谈 fancy 结构；
  • 也说明为什么 Rank 36 / 37 这类 TSM 线要先过 TSM vs drift / no-overlap / cost 诚实门，否则容易把系统层收益误认成信号层 alpha。

更直白地说：这篇论文更适合当 baseline doctrine，不适合直接塞进当前 Scout Fast Lane 当一条已冻结的 trade on / trade off / exit / hold 模板。

4. 可复刻的最小实验

  • 研究假设：如果 15m crypto 里真有 own-past persistence，那么即使把规则压到很朴素的“最近 N 根净涨跌方向”，也应在某些稀疏、少重叠、扣成本的切片里留下正 pocket。
  • 一个可计算定义：trade on = 最近 16 / 32 / 48 根 15m bar 的累计收益为正(做多)/负(做空)；trade off = 方向翻回中性或持有满固定 horizon，并强制 no-overlap。
  • 最小回测切口：BTC / ETH / SOL，120d 15m，next-bar open，持有 8 / 16 / 24 根，成本先看 6 / 10 / 15 bps per side。
  • 先看 2 个指标：cost-after mean_total_return 与 trade count / no_trade_ratio。如果连最朴素基线都完全站不住，再去加更复杂的 confirmation 多半只是在装饰噪音。

5. 风险与保留意见

  • 这篇论文的核心证据来自月级别期货，不是当前 desk 的 15m crypto；时间尺度、交易成本、市场结构都不同，不能直接拿收益幅度来套。
  • 我这轮拿到的是开放摘要页与文献元数据，不是完整逐节重读版；因此这里更适合把它当“母体结论 reminder”，不是细节级 replication brief。
  • 真要落到当前主线，必须补 short-horizon / no-overlap / friction / cross-asset honesty，否则很容易把长周期结论误套到短周期噪音里。

6. 对当前排班的意义

当前它最合适的定位是：给 desk 留下一条更硬的 baseline alpha 母论文提醒。它能帮助之后的 scout / validation 线少走弯路，但不会单独重新打开当前 Run 2 的 fast lane，也不会改变 Run 3 仍被 execution surface 卡住的事实。
