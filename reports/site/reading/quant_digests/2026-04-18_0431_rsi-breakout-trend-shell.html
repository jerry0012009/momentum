先回答 base alpha：说得清楚，就是“趋势中的 RSI breakout continuation”。 这不是 filter 伪装，也不是又一篇 RSI oversold 反弹。更准确地说，这个 repo 值得 intake 的地方是：

> 它把“动量已经起来了，再追第二脚”这件事，封成了一个带趋势过滤、ATR 风控、动态仓位和成本假设的完整策略壳。

关键源码里最重要的几条规则很清楚：

  • RSI(14) 上穿 65 才入场；
  • 若 close > EMA200 且 ADX > 25，阈值放宽到 60；
  • 同时还要求 close > EMA200、ADX > 20、volume > volume_SMA20；
  • 出场主壳是 4x ATR trailing stop，另有 RSI < 30 的 emergency exit；
  • 仓位不是固定手数，而是按 risk_per_trade / stop_distance 动态缩放，最多 3x 名义杠杆；
  • README 还写了 walk-forward optimization 和 bootstrap Monte Carlo。

翻成人话：这份 repo 不是在赌“RSI 高了就一定继续涨”，而是在赌：

> 只有当长趋势、趋势强度、成交量三件事都先对了，RSI 的向上突破才更像 continuation 的确认。

2. 核心结论

  • 一句话核心结论： 这份 repo 最值得记住的，不是“RSI 65 很神”，而是 trend filter + strength filter + volume filter + RSI breakout 这套完整 trend shell：先把坏环境剔掉，再追第二段动量。
  • 一句话证明方式： 我先按源码把 entry/exit/sizing 读清，再用 Binance USDⓈ-M 公共 15m/5m 数据做 portability probe，看这条 4h 壳压到我们关心的短周期后，还剩多少 gross / net edge。
  • 最重要的 first verdict： 它是合格的 raw alpha / 完整策略候选，但 current 15m/5m transfer 明显不过成本。 更像“4h shell 可借鉴，短周期不能直接照抄”。

3. 这份 repo 最值得记住的 4 个点

3.1 这是顺势 breakout，不是传统 RSI 超卖反转

它的入场不是 RSI < 30 抄底，而是：

  • 先确认 close > EMA200；
  • 再确认 ADX > 20；
  • 再确认 volume > SMA20；
  • 最后才要求 RSI 向上穿越 65。

所以它的 base alpha 很明确： 趋势已经建立后，RSI breakout 更像 continuation，而不是噪音。

3.2 bull regime 里会主动降低追涨门槛

源码里有个很 desk-friendly 的小分支：

  • 如果 close > EMA200 且 ADX > 25，RSI entry threshold 会从 65 降到 60。

这其实是在表达一句很朴素的人话： 强牛段里，别等到动量强到夸张才上车。

这不是新奇理论，但它是一个可直接拆出来单测的旁支：

  • fixed threshold
  • vs regime-adaptive threshold

3.3 这份壳把 sizing / cost 一起带上了

repo 不是只给一个 entry 条件，而是把完整 shell 几乎都写了：

  • ATR 决定 stop distance；
  • risk_per_trade 决定 position size；
  • max_position_pct 限制名义杠杆；
  • 还额外扣了 fee / slippage / funding proxy。

所以它符合当前优先级里更高的一档： 不是只给 raw alpha 句子，而是给了能直接复刻的完整策略骨架。

3.4 source audit 里有个重要保留：README 说有 10x ATR TP，但可见执行主循环更像“trail/衰竭退出”壳

README 把 exit 写成：

  1. 4x ATR trailing stop
  2. 10x ATR take profit
  3. RSI < 30 emergency exit

但在可见 v5 执行主循环里，tp_hit 被初始化为 False，我没有看到它在出场分派前被真正置成 True。实际跑出来的 portability probe 也几乎全是：

  • trailing_stop
  • trend_exhaustion
  • rsi_emergency

也就是说，这份 repo 的真实可见壳，当前更像： > RSI breakout 入场 + ATR trail / EMA20 失守退出

这不是坏事，但它提醒我们：不能只抄 README，要抄实际代码。

4. public-data portability probe：压到 15m/5m 后还站不站得住

4.1 最小实验口径

我没有硬复刻 repo 的 4h 2024~2026 全样本，而是做了一个更贴近当前 desk 的短周期 transfer：

  • 数据：Binance USDⓈ-M public klines
  • 15m：近约 120d，ETHUSDT / BNBUSDT / SOLUSDT
  • 5m：近约 45d，ETHUSDT
  • 规则：沿用 repo 的 EMA200 + ADX + volume + RSI breakout 逻辑
  • 出场：按可见执行主循环，用 4x ATR trail / EMA20 trend exhaustion / RSI<30 emergency
  • 成本代理：round-trip fee 20bps + slippage 10bps，再加简化 funding proxy

4.2 结果先给结论

#### 15m / ETHUSDT

  • 64 笔
  • gross mean 约 +15.79 bps/笔
  • net mean 约 -30.08 bps/笔
  • gross 胜率约 37.5%
  • net 胜率约 25.0%
  • 中位持有约 27 bars（约 6.75h）

#### 15m / BNBUSDT

  • 58 笔
  • gross mean 约 +3.53 bps/笔
  • net mean 约 -45.38 bps/笔
  • cumulative net 约 -23.43%

#### 15m / SOLUSDT

  • 65 笔
  • gross mean 约 +14.29 bps/笔
  • net mean 约 -32.41 bps/笔
  • cumulative net 约 -20.26%

#### 5m / ETHUSDT

  • 70 笔
  • gross mean 约 +6.84 bps/笔
  • net mean 约 -41.26 bps/笔
  • 88.6% 出场都来自 trailing stop

4.3 这些数真正说明了什么

  1. raw alpha 本体不是 0。

    2. ETH/SOL 15m 的 gross mean 还在正区，说明“趋势里的 RSI breakout continuation”不是完全瞎编。

  2. 但 thickness 明显不够。

    3. 一旦按 repo 自己宣称的 production-ish friction 去扣，15m/5m 都明显转负。

  3. 5m 比 15m 更差。

    4. 这说明这条壳不是天然适合更快频率；压得越短，越容易被噪音和摩擦吃掉。

  4. 出场更像 trail-driven，而不是 TP-driven。

    5. 这也解释了为什么 gross 胜率不高：它在赌少数趋势尾段能跑很长，而不是高胜率小止盈。

5. 为什么它和当前项目有关

这轮选它，不是因为 repo 本身特别强，而是因为它补了当前 intake 里一个值得保留的方向：

  1. 它是 raw alpha，而且是偏顺势，不和最近几篇 pairs / MR / microstructure 重复。
  2. 它给的是完整策略壳。

    3. 这比只给一个“RSI breakout 可能有用”的想法更值钱。

  3. 它明确告诉我们：有些 4h 趋势壳，不能直接缩到 15m/5m。

    4. 这个负结论本身就很值钱，因为能防止我们把慢频壳误搬到短周期。

  4. 它还能拆出两个可继续测的旁支：
  • regime-adaptive RSI threshold
  • EMA200 + ADX + volume 到底谁在贡献 edge

5.5 策略拆解（必填）

  • 方向属性：单资产 / 顺势 / 动量 continuation
  • 基础 alpha：趋势已建立时，RSI breakout 继续沿原方向推进
  • regime：close > EMA200 且 ADX > 20/25
  • filter / veto：volume > SMA20，bull regime 下阈值从 65 放宽到 60
  • risk / sizing / execution overlay：4x ATR trailing stop、动态仓位、最大 3x 名义杠杆、fee/slippage/funding cost proxy

6. 可复刻的最小实验

6.1 最小研究假设

对 short-cycle crypto 来说，慢频 trend shell 直接压到 15m/5m 往往太薄；但其中某些组件——尤其 regime-adaptive RSI threshold——可能仍有局部价值。

6.2 一个更 desk-friendly 的下一步

不要整壳继续硬跑，先拆成 ablation：

  1. EMA200 + RSI breakout 仅保留两件事；
  2. 再单独加 ADX > 20；
  3. 再单独加 volume > SMA20；
  4. 最后比较 fixed RSI65 vs bull regime 下 RSI60。

6.3 下一步怎么测

  1. 先做组件拆解，不要再跑完整 4h 壳的 15m 缩放版。

    2. 先回答 edge 到底来自 EMA200、ADX、volume、还是 adaptive threshold。

  2. 把 exit 改成真正 short-cycle 的 fixed horizon 对照。

    3. 比如 4 / 8 / 12 bars time-box，对比 trail exit，确认是不是 exit 过慢把 edge 吃掉。

  3. 做 maker/taker 双成本梯度。

    4. 当前 verdict 是 taker-ish friction 下明显不活；若 maker-first 仍不活，就该直接降级。

  4. 只留 ETH / SOL，先放弃 BNB。

    5. 本轮 gross 最差的是 BNB，没必要在弱腿上继续烧时间。

  5. 如果仍想保留这条线，更像该把它降级成 shared gate。

    6. 例如让 EMA200 + ADX + volume 去服务别的 breakout / pullback raw alpha，而不是坚持把 RSI breakout 本体当主策略。

7. 风险与保留意见

  • 这是一份 2026 新 repo，不是论文；所谓 production-grade 主要来自作者自述与代码结构，不是同行评审证据。
  • repo 主样本是 4h，而我们 desk 的默认目标是 5m / 15m；本轮 negative transfer 其实不意外。
  • 当前 portability probe 只是 first verdict，不是 walk-forward 正式回测；但它已经足够说明“不能直接照搬”。
  • 如果后续只抽组件而不继续整壳，这篇依然值得保留；因为它提供的是 一个完整、可读、可拆的 trend shell 母板。

8. first verdict

这篇东西属于 raw alpha，而且可独立复现、也能落成完整策略壳。但对当前 short-cycle desk，更老实的结论是：

> 完整壳值得学习，短周期直译不值得照抄。

如果要把它放进当前研究池，我会把它标成：

  • 主标签：raw alpha / complete shell
  • 当前状态：可借鉴，但 short-cycle first verdict 偏负
  • 最值得保留的旁支：regime-adaptive threshold + trend shell 拆件
