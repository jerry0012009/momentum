为什么选 Rank151

它是活的研究线

Rank151 不是归档负例，也不是已经被 future/lookahead 审计打死的线。它已经走过 fresh intake -> rolling split -> launch admission -> paper runner 这一整条链路。

它的本地研究最完整

这条线同时有 digest、source intake、rolling split、launch admission 和 paper runner 页面，所以很适合做“一条 rank 是怎么从来源变成网站上的研究资产”的完整拆解。

更关键的是，Rank151 的研究结论有一个很适合讲明白的反直觉点：EMA / breakout 对齐分数不是越高越好。这比“又发现了一个新 trigger”更有解释价值，因为它改变的是读者如何理解趋势分数本身。

原始来源到底讲了什么

Source thesis

原始来源的主线不是单根 K 线择时，而是一个更完整的趋势跟随框架：在流动性较高的加密资产上，用 EWMAC + breakout 做连续仓位，再叠加风险过滤、执行优化和部分跨资产对冲。

README 里的关键句，翻成人话

  • 不是 binary 的 long/flat，而是 continuous positioning。
  • 信号来源包含 EWMAC 和 breakout。
  • 趋势仓位要受 risk-off regime filter 约束。
  • 完整系统还包含 execution optimization 和部分 hedging。
也就是说，这个来源本来就更像“完整 trend engine 的研究仓库”，而不是一条可以直接拿来当单独 alpha 排名的因子论文。

本地把它翻译成了什么

我们继承的部分

本地真正 intake 的，是 EWMAC 与 breakout 的对齐度更适合作为 admission / sizing gate 这个思想，而不是把整个仓库原样搬进 desk。

我们没有照搬的部分

没有照搬它的市场值选池、daily 级别组合框架、risk-off 总控、hedging 执行层，也没有把“分数越高越强”当成默认真理。Rank151 只提炼出一个更窄、更诚实的 shared gate。

IC 与数理逻辑

这条线最容易被误读的地方就在这里。如果你把 align_score 当成“越大越好”的单调因子来算 IC，它并不好。 但这并不和研究结论冲突，因为 Rank151 的 thesis 本来就不是单调排序，而是 中段优于两端的 band-pass。

当前最诚实的 verdict

它是什么

把 EMA / breakout 对齐度当作一个带通型仓位闸门：让中等强度的延续 setup 更大声，而不是默认追最极端、最容易 late-chase 的尾部分数。

它不是什么

  • 不是独立 raw alpha。
  • 不是“分数越高越该追”的单调趋势因子。
  • 不是整套 crypto-trend-follow 系统的完整移植。
  • 不是已经完成 raw-bar 在线重算的 live engine。

所以这页的结论不是“Rank151 的 IC 很高”，而是：Rank151 把一个来源仓库里的 continuous-positioning 思路，翻译成了一个更适合 desk 的 band-pass gate；它的价值来自读法被修正，而不是来自单调排序被放大。
