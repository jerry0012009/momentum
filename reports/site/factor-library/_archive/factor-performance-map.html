评价指标说明

指标定义用途
ICfactor value 与 future return 的 Pearson 相关性衡量因子预测能力
RankICfactor rank 与 future return rank 的 Spearman 相关性非参数，更稳健
ICIRmean(IC) / std(IC)衡量 IC 稳定性，>0.5 为较好
t-statmean(IC) / (std(IC) / √N)IC 均值显著性诊断
Quantile Spreadtop bucket 与 bottom bucket 的收益差可交易性诊断
Cost-adjusted扣除交易成本后的 spread实际可执行性
Capacity在流动性约束下能承载的资金量规模限制
