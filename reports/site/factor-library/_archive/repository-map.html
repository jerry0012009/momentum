📐当前真实架构

当前真实架构不是纯 src-package-driven，而是 scripts-driven research pipeline + partial reusable src components。

也就是说，当前 run 的主要执行入口在 scripts/，研究档案在 research/，可复用组件部分在 src/。未来如果要工程化，应逐步把稳定逻辑从 scripts/ 沉淀到 src/，但当前阶段不做重构。

⚖️Source-of-Truth 规则

  • 1 研究档案库（当前 run） — research/factor_runs/crypto_top50_factor_library/ 是研究 run crypto_top50_usdt_perp_1h 的审计档案，不是整个因子库框架。包含人工编写的计划/结项报告和自动生成的评估 CSV。未来的不同 universe run 会有各自的审计档案。
  • 2 透明度文档 — docs/factor_library_transparency/ 是人类可读的透明度文档源。PM 用这些文件理解因子库，需要与研究档案保持同步。
  • 3 展示网站 — reports/site/factor-library/ 是生成的网站输出，不应作为唯一数据源。所有内容都应可从研究档案和透明度文档重新生成。
  • 4 脚本目录 — scripts/ 包含可复现的生成逻辑。给定相同输入，产生相同输出。
  • 5 源代码包 — src/momentum/ 是可复用的 Python 包。修改需要代码审查。
  • 6 数据目录 — data/ 包含生成或缓存的数据，不应手动编辑。运行管道脚本重新生成。
  • 7 测试目录 — tests/ 保护逻辑和假设。修改 src/ 或 scripts/ 前必须运行测试。
