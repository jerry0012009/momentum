📊 主动买入因子 (Taker Imbalance)
数据来源: data/raw/ (taker-enriched bars) — 1h K线中包含 taker_buy_quote_volume 和 quote_volume 列。数据连续，无稀疏性问题。

taker_buy_delta_5h

5小时主动买入增量
CRYPTO_NATIVE TAKER NOT_PHASE9B
ratio - delay(ratio, 5) where ratio = taker_buy_quote_volume / quote_volume
Lookback: 5h
方向: NEGATIVE (sign-flipped)
Cross-sectional z-score: ✓
Winsorize: 1st-99th percentile
来源脚本: build_crypto_native_factor_values.py
状态: DIAGNOSTIC_PROBE

主动买入占比的5小时变化，捕捉短期买卖力量转变。短窗口对噪音敏感。

taker_buy_ratio_20h

20小时主动买入占比均值
CRYPTO_NATIVE TAKER NOT_PHASE9B
rolling_mean(taker_buy_quote_volume / quote_volume, 20)
Lookback: 20h
方向: NEGATIVE (sign-flipped)
Cross-sectional z-score: ✓
Winsorize: 1st-99th percentile
来源脚本: build_crypto_native_factor_values.py
状态: DIAGNOSTIC_PROBE

主动买入占总成交的比例，>0.5表示买方主导。单一维度，忽略成交规模。

taker_buy_zscore_20h

20小时主动买入Z分数
CRYPTO_NATIVE TAKER NOT_PHASE9B
zscore(taker_buy_quote_volume / quote_volume, 20) = (ratio - SMA20) / STD20
Lookback: 20h
方向: NEGATIVE (sign-flipped)
Cross-sectional z-score: ✓
Winsorize: 1st-99th percentile
来源脚本: build_crypto_native_factor_values.py
状态: DIAGNOSTIC_PROBE

主动买入占比的标准化偏离，异常值可能预示趋势。假设正态分布可能不成立。
