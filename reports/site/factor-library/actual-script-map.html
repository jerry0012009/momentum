6. Factor-Level Evaluation / 因子层评价

这是独立于 signal panel 的因子层评价。每个因子单独计算 vs forward return 的 RankIC (Spearman)。
字段内容
评价脚本scripts/evaluate_factors.py（H8/H8-R）
Parity guardscripts/check_factor_ic_parity.py（10/10 PASS, max diff 0.00e+00）
方法每个 timestamp 内 rank(factor_value) 与 rank(forward_return) 的 Pearson 相关系数。Direction-adjusted。
输出research/factor_runs/crypto_top50_factor_library/factor_level_evaluation/
公共页面factor-evaluation.html
已计算59 因子有 factor_values；因子层评价状态以 factor_level_evaluation_manifest.json 与 factor_library_state.md 为准
是否因子库主链路是
