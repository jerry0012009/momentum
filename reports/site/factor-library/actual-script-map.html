7. Signal Evaluation Framework：信号评价框架

本节解释当前信号不是只靠一个回测结果判断，而是通过 RankIC、分组收益、尾部诊断、变体网格、成本/流动性桥接等维度逐层筛查。

活跃入口点：scripts/evaluate_signals.py — 使用公共 momentum.signal_evaluation API 的规范 CLI 入口。
旧 Phase 10A/10A-R/10B/10D 脚本已归档至 archive/legacy_phase_scripts/phase10/，仅供历史参考。

7.1 当前活跃评价维度

评价维度目的当前结果（core_only）脚本
RankIC / 横截面排序预测力 判断信号排序和未来收益排序是否相关（Spearman correlation） 1h=0.0325(t=17.6) · 4h=0.0385(t=20.8) · 24h=0.0416(t=22.6) · 72h=0.0338(t=18.1)
RankIC 为正且 t-stat 高，说明有横截面排序信息；但不等于可交易收益		 scripts/evaluate_signals.py
Quantile Spread / 分组收益 判断高分组和低分组的未来收益差（top bucket - bottom bucket） core_only mean spread: 1h=-0.000306 · 4h=-0.001232 · 24h=-0.006742 · 72h=-0.016623
⚠️ RankIC 为正但 mean spread 为负，说明存在 bucket/tail 异常		 scripts/evaluate_signals.py
Direction / Quantile Consistency 检查 RankIC 方向与 top-bottom spread 方向是否一致 RankIC 正，但 top-bottom mean spread 负，方向冲突 scripts/evaluate_signals.py
以下维度属于历史扩展诊断或未来模块，当前 evaluate_signals.py 不直接支持：
  • Bucket / Tail Diagnostics — 检查极端 bucket 是否支配均值结果。旧 Phase 10B 脚本已归档，结果保留在 phase10b_*.csv。
  • Tail-aware Policy Design — 基于 tail 诊断设计 guard / direction policy。属于设计阶段，不是标准评价指标。
  • Variant Grid — 比较不同 signal variant × horizon × guard × direction policy 的 pass/fail。旧 Phase 10D 脚本已归档，结果保留在 phase10d_*.csv。

7.3 如果未来信号来自机器学习模型，如何复用评价框架？

可以复用的前提：ML 模型输出统一 signal panel：
timestamp / symbol / signal_name / signal_value / optional(model_version, feature_set, training_window)

只要满足这个接口，就可以复用：RankIC、quantile spread、direction consistency、bucket/tail diagnostics、variant grid、cost/liquidity bridge、paper monitoring。
不能直接复用的部分：
  • 当前 build_phase9b_signal_panel.py 里的固定三信号构造逻辑
  • 10C 针对当前信号 tail 问题设计的特定 policy
  • 任何硬编码当前 signal names / current run paths 的脚本

7.4 当前代码结构

当前 active structure 已完成：
  • src/momentum/signal_evaluation/ — 公共 API 包：rank_ic.py（向量化 RankIC）、quantile_spread.py（standard + legacy 模式）、consistency.py、_vectorized.py（向量化快路径）
  • scripts/evaluate_signals.py — 规范 CLI 入口，使用公共 API
  • scripts/run_signal_evaluation_parity_harness.py — parity 测试工具
  • 旧 Phase 10 脚本已归档至 archive/legacy_phase_scripts/phase10/
未来如需扩展（tail diagnostics、variant grid），应作为新模块加入 src/momentum/signal_evaluation/，不恢复旧脚本。

7.5 当前信号评价结论摘要

当前核心信号 signal_v0_core_only 在 RankIC 上显著为正，但 mean quantile spread 为负，说明它不是一个已经干净验证的 alpha。10A-R / 10B / 10D 的作用是解释方向冲突、尾部异常和变体筛查。Phase 11A/11B 显示成本仍是核心约束。Phase 12B 的 30-day rolling diagnostic 提供近期观察证据，但不是 future paper validation。当前结论是：该信号可以继续 paper diagnostic，不可解释为可交易策略。
